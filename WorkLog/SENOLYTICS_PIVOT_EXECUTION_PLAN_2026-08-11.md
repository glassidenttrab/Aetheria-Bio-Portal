# 세놀리틱스(안티에이징) 집중 전환 작업계획서
**작성일**: 2026-08-11
**전제**: `SUBSCRIPTION_VIABILITY_AND_STRATEGY_2026-08-11.md`에서 결정한 "시나리오 B — 니치 버티컬 집중"을 실행하는 단계별 계획. "전신 10대 의학 분야" 대신 **안티에이징/노화 세놀리틱스 한 분야**를 진짜 데이터로 깊게 채우고, 나머지 9개 분야는 정직하게 재라벨링합니다.

이 문서는 코드로 자동화할 수 있는 부분과, **대표님이 직접 하셔야 하는 리서치/의사결정 부분**을 명확히 구분합니다. 후자를 건너뛰면 이 전환 자체가 의미가 없으므로, 순서대로 진행하는 것을 권장합니다.

---

## 0. 핵심 개념 먼저 정리 (기초)

- **세놀리틱스(Senolytics)**: 노화된 채 죽지 않고 남아 조직에 염증을 일으키는 "노화 세포(senescent cell)"를 선택적으로 제거하는 약물/치료법 분야. 현재 코드의 `longevity` 부서(`LONGEVITY_TARGETS`)에 BCL2, SIRT1 두 표적이 이미 있습니다 — 완전히 새로 시작하는 게 아니라 이 부서를 깊게 파는 것입니다.
- **FTO(Freedom-to-Operate)**: "이 기술/화합물을 상업화해도 남의 특허를 침해하지 않는가"를 판단하는 것. 정식 FTO 의견은 변리사가 실제 특허 전문(claim)을 분석해야 나옵니다. **우리는 이걸 흉내 내지 않고, "특허 동향 요약(참고용, 법적 자문 아님)"으로 명확히 다시 정의합니다.**
- **시장가치 추정**: 정식 시장조사 보고서(Evaluate Pharma 등, 유료) 없이는 정확한 숫자를 낼 수 없습니다. 대신 공개된 라이선싱 딜 규모, 임상 단계, 상장 바이오텍 공시 등 **출처를 명시한 참고 자료**로 대체합니다.

이 두 가지를 "진짜 데이터"가 아니라 "출처가 명확한 참고 자료"로 정직하게 재정의하는 것이 이번 전환의 핵심입니다.

## Phase 0 — 범위 확정 (1일 이내, 대표님 의사결정)

**목표**: 무엇을 깊게 다룰지 숫자로 확정한다.

- [ ] **표적 개수 확정**: 처음엔 5개로 시작 권장(기존 BCL2, SIRT1 포함 + 신규 3개). 너무 많으면 리서치가 끝나지 않음.
- [ ] **표적 선정 기준 확정**: 예 — "임상 2상 이상 진행 중이거나, 최근 2년 내 유의미한 라이선싱 딜이 있었던 세놀리틱스 표적"
- [ ] **후보 표적 브레인스토밍**: 이미 잘 알려진 세놀리틱스 표적 예시(리서치 시작점으로 참고만 할 것 — 검증 필요):
  - BCL2 (이미 있음)
  - SIRT1 (이미 있음)
  - BCL-xL (BCL2L1)
  - p16INK4a / CDKN2A (노화 세포 마커, 직접 표적은 아니지만 리서치 지표로 중요)
  - Dasatinib+Quercetin 병용 관련 표적(임상적으로 가장 앞서 있는 조합)

> **여기서 제가 할 수 있는 일**: 이 5개 후보에 대해 PubMed/ClinicalTrials.gov/OpenTargets 실시간 조회로 "현재 임상 단계·논문 수·연관 질환"까지는 바로 뽑아드릴 수 있습니다. 최종 선정은 대표님 판단입니다.

**산출물**: 최종 확정된 표적 리스트 5개 (텍스트로 저에게 알려주시면 됩니다)

## Phase 1 — 리서치 (1~2주, 전적으로 대표님 몫)

**이 단계가 이번 전환의 진짜 핵심입니다. 코드로 대신할 수 없습니다.**

각 표적(5개)마다 아래 항목을 조사합니다. 표 형태(엑셀/구글시트/마크다운 아무거나)로 정리해주시면 제가 코드에 반영합니다.

### 1-A. 특허 동향 (무료 도구로 가능)
- [ ] [Google Patents](https://patents.google.com)에서 표적명 + "inhibitor" 또는 "senolytic"으로 검색
- [ ] 최근 3~5년 내 출원된 관련 특허 3~5건의 출원인(회사명), 출원일, 특허 상태(등록/출원중/소멸) 기록
- [ ] **주의**: 이건 "누가 이 분야에서 특허를 내고 있는가"를 보여주는 동향 자료입니다. "우리 화합물이 이 특허를 침해하는지"는 판단하지 않습니다(그건 변리사 영역).

### 1-B. 임상/개발 현황 (제가 실시간 조회로 초안 제공 가능)
- [ ] 현재 임상 단계(전임상/1상/2상/3상/승인)
- [ ] 주요 개발사(있다면)
- [ ] 관련 논문 수 및 최근 3년 트렌드(늘고 있는지 줄고 있는지)

### 1-C. 시장/거래 참고 자료 (무료 공개 자료로 가능)
- [ ] 관련 라이선싱 딜이 있었다면: 딜 발표 보도자료(회사 홈페이지, BioSpace, FierceBiotech 등)에서 공개된 금액
- [ ] 상장된 관련 회사가 있다면: 해당 회사 IR 자료의 파이프라인 설명
- [ ] 없으면 "공개된 거래 사례 없음"으로 명시(추측 금액을 넣지 않음 — 이게 지금까지의 문제였음)

**산출물**: 표적 5개 × 위 항목이 채워진 리서치 노트

## Phase 2 — 데이터 구조 반영 (리서치 완료 후, 코드 작업 — 저)

리서치 결과를 받으면 제가 진행합니다:

- [ ] `neuroLongevityEngine.ts`의 `LONGEVITY_TARGETS`를 리서치 결과 5개로 교체/확장
- [ ] `hitCandidates`의 `patentFTO`, `estimatedMarketValue` 필드를 정직한 이름과 표시 방식으로 변경:
  - `patentFTO` → 특허 동향 요약 + "법적 자문 아님, 참고용" 디스클레이머 UI에 항상 노출
  - `estimatedMarketValue` → 출처 링크가 있는 참고 자료만 표시, 없으면 "공개 자료 없음"으로 명시(빈 값을 가짜 숫자로 채우지 않음)
- [ ] 표적 상세 화면에 "이 리포트는 공개 자료를 기반으로 편집되었으며 법적/투자 자문이 아닙니다" 고지 문구 추가(8개 언어)

**검증**: `npx tsc --noEmit -p .`, `npm run build`, `npx vitest run`, `npx eslint .` 통과 확인 후 커밋

- **내용**:

### 🗄️ [과제 4] Supabase PostgreSQL DB 4대 테이블 실시간 연동
- **내용**:
  - `src/services/supabaseService.ts` 데이터베이스 서비스 레이어 구현
  - `users` 테이블: 사용자 프로필(이름, 소속, 직함), 구독 플랜, 쿼리 잔여 횟수 실시간 upsert/fetch 연동
  - `skill_audit_logs` 테이블: 38개 사이언스 스킬 실행 시 이력 실시간 자동 저장 및 내 연구 포털 연동
  - `subscriptions` 테이블: PayPal 결제 승인 시 정산 영수증 기록 및 유저 플랜 자동 승급 연동
  - `api_keys` 테이블: B2B 관제 콘솔 API Key 생성/조회/삭제 CRUD 연동
